# Papers and posters

Drop published papers, preprints, and conference posters here. Both images
(`.png`, `.jpg`) and `.pdf` files work — Jekyll copies this folder verbatim, so
anything placed here is reachable at `/images/papers/<filename>`.

## Naming

Use `lastname-venue-year.<ext>`, lowercase, hyphenated, no spaces:

```
joshi-iaai-2026.pdf
rudow-aaai-workshop-2026.pdf
makkuni-hopkins-symposium-2025.png
```

Spaces in filenames become `%20` in URLs, so avoid them.

## How these get used

Nothing here is displayed automatically. Once files are in place, they can be
linked from:

- a project entry in `_projects/*.md` (see the `projects:` list in each file)
- a news post in `_posts/`
- a person's entry in `_people/*.md`

Tell Claude what a file is and where it belongs and it will wire it up.
